# Writeups Cyber en Français

Writeups de challenges CTF TryHackMe et HackTheBox, rédigés en français.

Chaque writeup explique le raisonnement derrière chaque action, pas seulement les commandes. L'idée : si tu peux expliquer simplement une technique, c'est que tu l'as vraiment comprise. C'est la méthode Feynman appliquée à la cybersécurité.

**Site :** [managone.github.io/writeups](https://managone.github.io/writeups/)

---

## Ce que tu trouveras ici

Des writeups sur les thématiques suivantes :

- Enumération réseau et web (Nmap, Gobuster, smbclient)
- Exploitation web (injections, upload, RCE, broken auth)
- Brute-force (Hydra, John the Ripper, Hashcat)
- Stéganographie et OSINT
- Escalade de privilèges Linux (SUID, sudo, cron, Docker)
- Escalade de privilèges Windows (SMB, SeImpersonatePrivilege)
- CVE documentées (GhostCat, sudo bypass, Fuel CMS RCE)
